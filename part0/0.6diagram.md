sequenceDiagram
    participant browser as Navegador

    browser->>browser: Se agrega la nota al arreglo notes

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: Se envía la nota en formato JSON
    activate server
    Note right of server: El servidor guarda la nueva nota
    server-->>browser: HTTP 201 Created
    Note left of server: Respuesta JSON: {"message":"note created"}
